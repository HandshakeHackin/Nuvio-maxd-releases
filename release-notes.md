Nuvio Max'd 0.5.19 fixes automatic subtitle selection:

- Prefer matching subtitles included with the video file.
- Wait for file metadata before choosing an addon fallback.
- Keep manual selections, including Off, unchanged.
- Restore selected addon subtitles and styling after input reopening during a seek.
- Includes all playback and subtitle improvements from 0.5.18.

A simple changelog appears after updating; reopen it in Settings → What's new.

Download PPSA99288.zip for folder installation or NuvioMaxd-0.5.19-native.ffpfsc for image installation. Matching source, validation results and SHA256SUMS are included.

Experimental release. Native HDR, HDMI speaker routing and motion smoothness still require console confirmation. If native HDR is rejected, select Convert HDR to SDR.
