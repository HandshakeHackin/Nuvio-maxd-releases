Nuvio Max'd 0.5.20 adds update reminders for your install source:

- Choose Homebrew Store or GitHub/manual installation once on first launch.
- Save the choice locally and change it in Settings → Install source.
- Check for newer releases at startup, with reminders deferred during playback.
- Show store instructions for store installs and GitHub options for manual installs.
- Optional Ko-fi support button and QR code in Settings, plus a GitHub support badge.
- Keep all earlier subtitle and playback improvements.

Homebrew Store may receive a release later than GitHub. Background checks stay quiet when offline; retry from Settings → App updates.

Download PPSA99288.zip for folder installation or NuvioMaxd-0.5.20-native.ffpfsc for image installation. Matching source, validation results and SHA256SUMS are included.

Experimental release. Native HDR, HDMI speaker routing and motion smoothness still require console confirmation.
