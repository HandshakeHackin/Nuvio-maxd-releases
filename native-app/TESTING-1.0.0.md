# 1.0.0 console acceptance

Preserve a copy of your working installer. Install PPSA99288.ffpfsc through your usual homebrew manager, or use the packaged PPSA99288.zip. Stop the app before replacing its image. Existing profile settings are retained; the PS5 package revision is 06.000.000 and the app reports 1.0.0.

1. Confirm first boot, Max’d icon, changelog and normal Settings navigation. Search for a setting, select the result and confirm its original action works.
2. Confirm Nuvio sign-in, multiple profiles and profile-specific addons/library/history. Check Trakt pairing if used; never publish account tokens.
3. Open a known movie and episode. Test pause, resume, seeks, subtitles and audio-track changes while playing and paused. Position and pause state should remain stable.
4. Return to recent sources: eligible cached results should appear while refresh runs. Reload should bypass the cache. Switch profiles and verify results/preferences stay isolated.
5. Add your own M3U or Xtream source under Live TV. Check groups, search, favorites, recent channels, stop/start and returning to normal movies. Channels must not enter movie watch history.
6. On an anime with known timing coverage, check skip prompts and episode mapping. Missing coverage should not block playback.
7. Select Options → Watch trailer on a title. Check return to details; trailers must not alter watch history or trackers. A host-specific unavailable message is possible.
8. Exercise Native and optional EVO/VLC separately, including repeated 4K opens and stop/start. Verify actual HDMI/HDR on your display; build logs alone cannot confirm it.
9. Confirm updater shows 1.0.0 and does not offer older 0.5.x builds. A live update installation cannot be verified until the public 1.0 release exists.

10. Show playback controls on several streams. Verify resolution, HDR/SDR, audio channels and source badges. Change audio tracks and confirm the badges follow the selected track; hide the controls and confirm the badges disappear. Source HDR information can differ from the output conversion line.

If a failure occurs, use Settings → playback log and include app.log, log.txt and boot/crash logs available for PPSA99288. Remove stream URLs, playlist/server passwords, account tokens and personal details before sharing.
