# Nuvio Max'd identity

The product name is `Nuvio Max'd`, with a straight apostrophe. Download files
use `NuvioMaxd` where punctuation would complicate URLs or shell commands.
The public feed is `HandshakeHackin/Nuvio-maxd-releases`.

The rename keeps title ID `PPSA99288`, concept ID `99288`, content ID
`UP9000-PPSA99288_00-NUVIOPS5NAT00001`, and `/download0/nuvio` storage. Existing
login, settings and progress therefore keep their original location. The
bundled helper stays `nuvio-updater.elf`; it is never a separate download.
Nuvio account/Sync service names, endpoints and persistent sync-client IDs
continue to identify the external service and device. Upstream project names
in copyright notices and attribution retain their original spelling.

The icon and menu mark were prepared for Max'd with OpenAI image generation
and exported at the sizes used by the console UI. They ship under this project's
GPL-3.0-or-later license. The startup name uses the app's font renderer so it
stays sharp at each output resolution.

ShadowMount+ matches updates by title ID. ProsperoStore currently documents
that a tile's home-screen name does not change after an update. An older install
may keep its Nuvio PS5 tile name even though the running app is Max'd. Do not
change the title ID or erase saved data just to refresh the display name.
