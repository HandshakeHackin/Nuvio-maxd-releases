# Homebrew Store update

[1.0.0.1 on GitHub](https://github.com/HandshakeHackin/Nuvio-maxd-releases/releases/tag/v1.0.0.1-native-experimental) includes larger Live TV imports, experimental four-screen TV, PCM volume/boost and audio/subtitle sync controls.

The matching catalog record is [PPSA99288.json](PPSA99288.json). Its ZIP and icon point to the versioned release, with the verified GitHub asset digest and package revision `06.000.001`.

The catalog update is prepared for submission. Maintainers must approve/merge it and deploy the catalog before the Homebrew Store offers the new version. Check the listing’s version before installing. See this file on the main branch for the current submission status.

See [release notes](../RELEASE_NOTES.md) and [testing instructions](../native-app/TESTING-1.0.0.1.md). Four-screen mode needs four provider connections and physical-console testing; SD feeds are recommended.
