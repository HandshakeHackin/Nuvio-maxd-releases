Nuvio Max'd 0.5.27 — LOCAL TEST, NOT PUBLISHED

Settings now opens a category list. Cross opens a category, Circle returns to
that list, and Circle from the category list returns Home. Setting changes and
background refreshes retain focus. Saved setting keys are unchanged.

The controller lightbar makes a smooth 18-second teal → white → pink/purple
loop. It dims after boot. Reduced Motion holds steady teal.

Appearance & Lighting → Console light sync enables or disables the console
case-light effect immediately. The preference is saved locally and initially
on. A worker checks access to /dev/icc_indicator and validates its state layout
before writing. Supported consoles approximate the controller's RGB colour using
blue/white/amber channels, at up to five updates per second. This is not true RGB.
No additional payload is installed and no kernel patch is applied.

The worker leaves unsupported, inaccessible or ambiguous devices unchanged and
reports the status beside the setting. It restores the captured channel levels
when disabled, the PS menu opens, the app goes into the background, or on normal
app exit, provided the system has not already changed the lights. It backs off
instead of fighting system lighting. Toggle off and on to retry. Unexpected
process termination cannot guarantee restoration; console hardware compatibility
has not been verified in this build.
