# Max’d 1.0.0.5 — installation and checks

Close Max’d before replacing application files. Preserve saved user data and account/IPTV settings. Folder installs: extract `PPSA99288.zip` and copy the complete `PPSA99288/` folder to your usual homebrew location, without an extra nested folder level. Image installs: use `NuvioMaxd-1.0.0.5-native.ffpfsc`. Keep only the intended app copy in the location scanned by your loader. Confirm **1.0.0.5** in Settings → App updates. Title ID remains PPSA99288; contentVersion is 06.000.005.

- **Library:** Triangle/Options or Search enters a title query. Try multiple words, type/sort filters, no matches and Clear Search/Circle. Change profiles and Library sources to check isolation. Search matches loaded titles locally.
- **Programme guide:** Open Live TV with an Xtream account or an M3U playlist that supplies an XMLTV guide. Check Now/Next, channel groups, paging and source switching. Options → Set XMLTV guide URL allows a manual guide; the same menu offers refresh and on/off. Missing guide data should leave playback working. XMLTV IDs must match playlist tvg-id values. Raw/decompressed guide size is capped at 32 MiB.
- **New episodes:** In Library, check a series with synchronized watched history, at least one completed regular episode and a later aired/unwatched episode with a valid release date. Allow metadata to load near the cursor. Future/undated/special/in-progress episodes should not gain a new badge. Marking the new episode watched should remove or advance the indicator. Switch profile/progress source to check isolation.
- **Subtitles/covers:** Confirm external text subtitle sizes (including 150%/200%) and missing Library covers remain fixed. Authored ASS styles and bitmap captions retain their existing behavior.

For a problem, report version, firmware, playback engine and exact reproduction steps. Settings → App & Updates → Playback diagnostics shows diagnostic locations. Attach relevant `download0/nuvio/log.txt` and `download0/hui/dev/app.log` if present beneath the title’s `/mnt/sandbox/PPSA99288_000/` directory (suffixes can vary). Redact passwords, tokens, private playlist links and stream URLs. Do not upload account/settings files containing credentials.
