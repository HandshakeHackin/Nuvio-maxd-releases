# Start page and TV channel checks

1. Choose a start page in Settings → App & Updates. Restart and open the same
   profile. Check Home, Library and Live TV. Sports should use Home when disabled.
   Confirm nothing starts playing automatically.
2. Choose a TV group with L1. Restart, reload and switch sources. Each source
   should remember its group; a missing group should fall back to all groups.
3. Press Options on a channel, rename it, and search using both names. Its
   favorite and programme guide should remain intact after a reload. Clear the
   custom name to restore the provider's name.
4. Hide a channel. Restore it in Sources & filters → Hidden channels. Try Show
   all too. Favorites and source data should remain intact.
5. Open Backup channels for a channel with HD/SD or other copies. Choose one,
   including a hidden copy. Try the playback options while watching. The chosen
   stream should play; nothing should switch automatically.
6. Switch profiles and confirm these choices stay separate. Export and restore
   an encrypted configuration backup and check the new preferences.
7. Check the new dialogs in your menu language, including Arabic/CJK.

Existing signed-file verification remains available in Settings. Use a separate
test copy for file-tampering checks. Keep your app data when installing a build.
