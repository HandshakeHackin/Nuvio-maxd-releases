# 1.0.0.25 release checklist

1. Install the ZIP folder or FFPFSC image and check that App & Updates shows 1.0.0.25.
2. Open a normal movie or episode. Check Native, EVO and VLC playback, pause, seeking and audio/subtitle selection.
3. Check your selected menu language, Arabic/CJK text where used, and subtitle size/style.
4. Check MDBList library changes, movie and explicit episode watched marks, revisit/restart and carousel position.
5. Test a configuration-backup round trip in the matching profile, keeping the original backup.
6. Check your usual Live TV/USB playlist, media-server and provider setup.

For a problem report, include firmware, install format, playback engine and steps. Remove account details, private URLs and playlist contents from shared logs.
